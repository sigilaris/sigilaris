## Low findings

- **L1 Leader proposal uniqueness is in-memory only.** `reserveProposalEmission`/`markProposalEmitted` live in the pacemaker `stateRef`. A leader that signed and published a proposal, crashed and restarted inside the same view can sign a second proposal with a new timestamp for the same window. Voter safety holds because `claimConsensus` allows one vote per `(chainId, voter, height, view)`, but the leader exhibits observable equivocation; the durable controller already exists to persist a per-window proposal intent. The automatic conformance run never asserts one proposal per `(proposer, window)` or one vote per `(voter, window)` across sink snapshots. `PacemakerIntegrationRuntime.scala:1356-1400`; `V2RuntimeConformance.scala:676-800`.
- **L2 Shared transaction signature verifier has no V2 shape boundary and diverges across platforms.** Pre-existing since M1 (`SignatureVerifier.scala` unchanged in this range). JVM accepts `v ≡ 27..30 (mod 256)` and `v = 26` (equivalent to 28); Scala.js rejects them. For `p ≤ r < 2^256` with `r mod p` on curve, JVM rejects and JS returns a garbage key. No authentication bypass, but a `Signed[Tx]` accepted by a JVM node is rejected by a JS consumer. Consensus is JVM-only today. Also, legacy HotStuff `voteId` hashes malleable signature bytes, so an alias of an honest vote defeats gossip dedupe and can trip `duplicateValidatorVote`; preserved knowingly for M1/M2 replay. `CryptoOps.scala` (jvm `:219-274`, js `:169`); `Artifacts.scala:37-39`, `:750-767`; `Validation.scala:36-58`.
- **L3 Application journal is bound to the domain but not the local validator.** Recovery authentication checks voter membership in the historical validator set, not equality with the configured signer; `FileApplicationJournal` has no IDENTITY file unlike `CanonicalAppendLog`. A same-domain journal from another validator passes recovery and can flip the local claim state. Requires disk-rollback capability already acknowledged in the controller documentation. `SafetyJournalReduction.scala:40-55`; `JournalSafetyStore.scala:452-462`; `VotingRecoveryAuthentication.scala:171-181`.
- **L4 Bootstrap drain requirement is policy-driven.** An empty `policy.applicationDomains` passes the subset check and `verifyBootstrap` then requires zero drains for a PresentContent retired domain; handover explicitly requires the source-domain drain, bootstrap does not. `TransitionEvidenceVerification.scala:194-206`, `:650-676`, `:864-894`.
- **L5 Non-atomic fresh journal layout.** A crash between creating `blobs`/`journal.log` and moving HEAD leaves a directory that `validateLayout` rejects forever; `.HEAD-*.tmp`/`.blob-*.tmp` are tolerated but never removed. `FileApplicationJournal.scala:651-690`.
- **L6 Unreachable failure branch.** For a certified-fast source with an empty eligible lock subset `validateLock` fails first with `UnexpectedCertificate`, so the dedicated `InvalidLength` check never executes; the public case asserts only `isLeft`. Rejection is correct, the failure code differs from intent. `Certification.scala:500-522`, `:562-567`.
- **L7 Duplicate verifier slots.** `ProtocolManifest.validate` rejects identical `(slot, digest)` pairs but allows one slot bound to two digests. No plan or ADR text forbids it; flagged for a decision. `Inputs.scala:262-268`.
- **L8 Negative tests that cannot distinguish the firing guard.** Six ancestry mutations are asserted only as `detail.nonEmpty`; the `deadline = height(11)` mutation is rejected by either of two checks and the test passes if one is removed. `V2CanonicalAncestorConformance.scala:519-535`.
- **L9 Unbounded maps.** `MaintenanceFinalityDrive` attempt map never prunes. `MaintenanceFinalityDrive.scala:88-176`.
- **L10 Deadlock-by-convention.** The safety gate is a non-reentrant semaphore; any embedder `SafetyPublication`/`ProposalExecutionRepository` that reads `safety.snapshot` from inside `verifyProposal` self-deadlocks the vote path and, through the finalizer gate, the gossip sink. Only a doc comment guards this. `JournalSafetyStore.scala:225-233`; `ControllerApplicationSigning.scala:12-17`.
